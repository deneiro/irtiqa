IrtiQa — что на Маке и каким будет приложение

Два вопроса одной страницей: откуда три одинаковых значка и что ставить вместо них. Ничего ещё не удалено и не переименовано — это предложение.

1. Почему три одинаковых IrtiQa

Spotlight и Launchpad индексируют любой .app, где бы он ни лежал. У тебя их пять с одним именем и одной иконкой, три из них Spotlight показывает как приложения.

Чтобы история не повторилась: файл .metadata_never_index в src-tauri/target/ запрещает Spotlight индексировать папку сборок. После этого в Spotlight будет ровно одно приложение, в /Applications.

2. Имя

Сейчас продукт называется IrtiQa-Tauri и в заголовке окна, и в Dock, и в бандле. «Tauri» — это фреймворк, а не часть имени. Название самого продукта в vault помечено как «не выбрано» с сентября.

IrtiQa предлагаю

ارتقاء — восхождение. Имя уже твоё, уже в vault и в голове. Убираем только хвост «-Tauri».

productName: IrtiQa · com.eldar.irtiqa · окно «IrtiQa»

6. Порядок действий, если согласен

  1. Убрать лишнее. В корзину: .app.old, Second Brain.app, оба бандла в target/. Установленный IrtiQa-Tauri.app заменяется на шаге 4.
  2. Закрыть папку сборок от Spotlight. .metadata_never_index в src-tauri/target/.
  3. Переименовать. productName, identifier, заголовок окна, package.json, README и CLAUDE.md репо. Папка репо и проект в vault остаются IrtiQa-Tauri, чтобы не ломать ссылки. Новая иконка через npx tauri icon.
  4. Собрать и поставить. npx tauri build → /Applications/IrtiQa.app, запуск на настоящем vault, проверка «Утро».
  5. Записать. Обзор проекта в vault, log.md, ветка и PR в репо.
Смена identifier с com.eldar.irtiqa-tauri на com.eldar.irtiqa для macOS означает новое приложение: сохранённое положение окна сбросится, у бота привычек ничего не меняется (он живёт отдельно в launchd).

Нужно от тебя: имя (IrtiQa / Иртика / Утро / своё), эскиз иконки (A / B / C / своя идея) и «да» на удаление четырёх копий. После этого делаю шаги 1–5 за один заход.
